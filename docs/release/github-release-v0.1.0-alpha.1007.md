# ARIA 0.1.0-alpha1007

This candidate combines reliable background Agent Jobs, resilient MCP integration, a privacy-conscious Activity Journal, bilingual administration and owner-focused statistics.

Alpha1007 adds the final owner-review polish: concrete health checks, readable cost axes, correct container resource sizes, authoritative routing-index cleanup, full-width assistant tables, terminal Job controls and a compact chat actions menu.

See `docs/release/public-release-summary-alpha1007.md` and `CHANGELOG.md` for the complete scope and limitations.

## Upgrade

Back up ARIA first. Keep the current data/config mounts and Qdrant volume, and replace only the image with `fischermanch/aria:0.1.0-alpha.1007`. Review MCP trust settings after upgrading.
