# Notizen

Stand: 2026-07-09

## Zweck

Notizen sind ARIAs Markdown-Arbeitsbereich. Sie sind bewusst von Memory getrennt: Eine Note ist ein bearbeitbares Dokument, während Memory semantische Fakten, Präferenzen, Dokument-Chunks und gelernte Erfahrung speichert.

## Arbeiten mit Notes

Unter `/notes` kannst du:

- neue Markdown-Notizen erstellen
- vorhandene Notes bearbeiten
- Notes in Ordnern organisieren
- Notes aus Karten oder Editor in einen anderen Ordner verschieben
- die dichte Listenansicht für schnelles Scannen nutzen
- mehrere Notes auswählen und gemeinsam verschieben

Beim Verschieben aktualisiert ARIA Markdown-Pfad und Frontmatter. Wenn Notes indexiert sind, wird der Notes-Index passend nachgezogen.

## Inbox und Ordner

Die Inbox ist der neutrale Startort für unorganisierte Notes. Bestehende Ordner werden im Editor und beim Verschieben angeboten. So kannst du Ordnung herstellen, ohne Pfade von Hand zu bearbeiten.

## Suche und Index

Notes können für Suche und Kontext indexiert werden. Der Index ist abgeleitet. Wenn du eine Note löschst, soll auch der zugehörige Indexeintrag entfernt werden.

## Unterschied zu Memory

Nutze Notes für:

- Arbeitsnotizen
- Entwürfe
- Meeting- oder Projekttexte
- längere Markdown-Inhalte

Nutze Memory für:

- stabile Fakten
- Präferenzen
- Dokument-RAG
- Experience Memory und gelernte Muster

## Gute Tests nach einem Update

- neue Note in einem vorhandenen Ordner erstellen
- Note aus einer Karte in einen anderen Ordner verschieben
- Note im Editor verschieben
- mehrere Notes in der Listenansicht markieren und verschieben
- danach Suche/Index-Verhalten prüfen
